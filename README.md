## 目前版本：自由網路呈現（資料模型 v3）

參照使用者指定的 Claude Artifact 呈現方向，改為米色全畫面自由力導向網路與右上浮動控制面板，不再使用三欄長圖。三層是生活與工作重心、知識關鍵字、專案與實踐，以大／中／小節點區分。點選不會把網路切成孤立群組。Claude 和其他工具只出現在來源明細，不是圖上的中心。

控制包含七類獨立勾選、顯示層級 1–3、標籤層級 0–3、搜尋、月份、重排、置中、重設。滑過或鍵盤聚焦節點突顯直接鄰接；點選開啟可關閉明細。拖曳後固定、雙擊或明細按鈕解除，重排清除全部固定位置。位置只保留在當次頁面，不宣稱跨次儲存。手機預設收合控制面板。

實線代表編輯分類，虛線由原始共現關係投影至知識關鍵字；全期間主圖為單一連通網路，但單日證據不足時不強行補線。每條虛線可點開檢查原始節點對與依據；共現只是待確認線索，不是因果、完成認證，也不加總可能重疊的來源數。月份／日期篩選只保留該期間有紀錄的關係，證據明細標示各組統計日期區間。

## 使用

以瀏覽器開啟 `public/index.html`，或部署 `public/`。拉住節點可牽引相連項目，放開後固定該點，其餘逐漸回穩。點專案查看匿名來源，點虛線或明細關聯按鈕看證據。滾輪以游標為中心縮放，拖空白處平移；置中重新配合畫面大小。節點與標籤維持可讀的螢幕尺寸，不因縮放變成細小文字。

自動檢查：96 節點三層、單一連通網路、26 條去重橋接及逐條來源對帳、53 具名專案保留、月份搜尋與公開隱私、各顯示層級及分類取消。運動測試包含拖曳牽引、持續固定／解除、含／不含共現連線的冷卻穩定性。

## 隱私與發布範圍

`public/` 僅一個 HTML，內含主題、日期與匿名統計。不包含原始對話、筆記原文、文件標題、私人網址、帳號、本機路徑或私密索引。原始來源與匯入程式留在使用者本機，不放此儲存庫。

Netlify 設定禁止搜尋引擎索引、外部網路請求及嵌入；這不是登入保護，有網址的人仍可讀取公開版。公開內容限上述去識別資料。
