# 大乃的知識星圖：2026 六至八月

可拖曳、彈性牽引、平移、縮放、按月／單日篩選與搜尋的靜態互動網頁。不依賴外部套件、不連接後端。

## 使用

以瀏覽器開啟 `public/index.html`，或部署 `public/`。拉住節點可牽引網路，放開後逐漸穩定。點節點查看匿名來源分布，勾選「待確認」探索共同提及。

## 隱私與發布範圍

`public/` 僅一個 HTML，內含主題、日期與匿名統計。不包含原始對話、筆記原文、文件標題、私人網址、帳號、本機路徑或私密索引。原始來源與匯入程式留在使用者本機，不放此儲存庫。

Netlify 設定禁止搜尋引擎索引、外部網路請求及嵌入；這不是登入保護，有網址的人仍可讀取公開版。公開內容限上述去識別資料。

## 驗證

```sh
node test-public.cjs
node test-physics.cjs
```

範本為 `template.html`；資料嵌入於 `public/index.html`。更新範本須重新產生 HTML。檢查包含日期範圍、資料對帳、敏感資訊、節點連線與完整網路的運動穩定性。

## 部署

以 Netlify CLI 部署 `public/`，設定在 `netlify.toml`。不部署工作目錄上層或私人來源。每日排程不在這次發布範圍。
