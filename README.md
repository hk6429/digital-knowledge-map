三欄依序是 7 個生活與工作重心、19 個知識關鍵字、70 個專案與實踐，總覽完整呈現 96 個節點；長圖可以上下與左右捲動。點重心或關鍵字聚焦時，保留一跳相鄰的共現關鍵字及其重心。Claude 和其他工具只出現在來源明細，不是圖上的中心。

89 條實線代表編輯分類，26 條虛線由原始共現關係投影至知識關鍵字，完整六至八月主圖為單一連通網路。每條虛線可點開檢查其原始節點對與依據；共現只是待確認的線索，不是因果、完成認證，也不把可能重疊的來源數加總。月份篩選只保留該月有紀錄的關係，證據中的來源筆數明示為整期統計。

七個重心：國文教學、學生學習與評量、自我領導與班級經營、資訊組與校務、教師成長與分享、閱讀寫作與創作、生活與理財。分類是可調整的用途詮釋，不是因果認證。生活面向目前主要有理財資料，沒有臆造家庭或健康紀錄。

原來 83 個來源索引節點、152 條原始連線、53 個具名專案與所有來源統計仍保留於匯出資料。新的主題、關鍵字、專案／實踐共 96 節點採分層顯示；工具不進主圖。

`reframe.mjs` 可將原始去識別資料轉換為新版：

## 使用

以瀏覽器開啟 `public/index.html`，或部署 `public/`。拉住節點可牽引相連項目，放開後逐漸穩定並保留三欄結構。點專案查看匿名來源，點虛線或右側關聯按鈕看證據。一般滾輪捲動；Ctrl／Command 加滾輪或加減按鈕縮放。手機使用可捲動畫布，不把完整圖硬縮到無法辨讀。

v3 自動檢查：96 節點三層、單一連通網路、26 條去重橋接及逐條來源對帳、53 具名專案保留、理財聚焦仍連回教育工具設計、月份搜尋與公開隱私。另驗證含／不含共現連線的冷卻穩定性，以及三欄錨點不被拉成一團。

## 隱私與發布範圍

`public/` 僅一個 HTML，內含主題、日期與匿名統計。不包含原始對話、筆記原文、文件標題、私人網址、帳號、本機路徑或私密索引。原始來源與匯入程式留在使用者本機，不放此儲存庫。

Netlify 設定禁止搜尋引擎索引、外部網路請求及嵌入；這不是登入保護，有網址的人仍可讀取公開版。公開內容限上述去識別資料。

## 驗證

```sh
node test-public.cjs
node test-physics.cjs
```

範本為 `template.html`；資料嵌入於 `public/index.html`。更新範本須重新產生 HTML。檢查包含日期範圍、資料對帳、敏感資訊、節點連線與完整網路的運動穩定性。

## 部署

以 Netlify CLI 部署 `public/`，設定在 `netlify.toml`。不部署工作目錄上層或私人來源。每日排程不在這次發布範圍。
